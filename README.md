## 📖 What is this?

**EarthDrive-BeamNG** is an alternative, highly optimized build of the famous Earth map mod for BeamNG.drive. It transforms the game from a set of static, limited maps into a massive, endless journey across the real world.

Using real LiDAR elevation data, satellite imagery, and OpenStreetMap data, this mod procedurally generates roads, bridges, buildings, and regional vegetation on the fly. You can search for your hometown, set a GPS route to another country, or just pick a random highway and drive. 

The world streams in real-time as you move, powered by a local server that caches the terrain data. To prevent physics glitches at high speeds or long distances, the mod utilizes a **Floating Origin** system that keeps your vehicle constantly centered in the engine's memory.
